# 🔥 BIZON PROMO SPAMMER 🔥

**Azərbaycan dilində**

Bu script `api-promo.bizon.az` endpointinə random 7 simvolluq kodlar göndərir.  
Telefon nömrəsi daxil edin, kod hər dəfə random yaradılır.

## Nə edir?
- `POST` atır `https://api-promo.bizon.az/submit`
- `phone`: `0---------` (yalnız Azərbaycan nömrəsi)
- `code`: 7 simvol (böyük hərf + rəqəm)
- Cavabı ekrana basır

## Quraşdırma

```bash
pip install requests
Bash python main.py
```
